# SistemaTareas

Un sistema sencillo de gestión de tareas desarrollado en Python para practicar el flujo de trabajo colaborativo con Git y GitHub.

## 🚀 Estructura del Proyecto

- `main.py`: Punto de entrada que ejecuta la secuencia demostrativa del sistema.
- `tareas.py`: Módulo que contiene las funciones para agregar, listar y marcar tareas como completadas.
- `README.md`: Documentación del proyecto.

## 🛠️ Requisitos e Instalación

1. Asegúrate de tener instalado Python 3.x.
2. Clona este repositorio o descarga los archivos.

## 💻 Ejecución

Abre tu terminal dentro de la carpeta del proyecto y ejecuta:

```bash
python main.py
